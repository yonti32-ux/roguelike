Drop optional music tracks here to replace the built-in procedural ambience.

Supported filenames (first match wins):
  menu.ogg / menu.wav / menu.mp3
  explore.ogg / explore.wav / explore.mp3
  battle.ogg / battle.wav / battle.mp3

Tips:
  - Prefer short seamless loops (OGG).
  - Keep them quieter than SFX; the game already ducks music volume.
  - If no files are present, procedural ambient beds are used automatically.
